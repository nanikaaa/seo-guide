C1 · A22

Fix the 404s on the published test site

High

First try Settings › Permalinks › Save in the test site admin. If /right-core/news/ still shows the server's plain "Not Found" page, upload this file as right-core/.htaccess. FTP clients often hide files that start with a dot; turn on "show hidden files".

On production, WordPress is at the domain root: use RewriteBase / and RewriteRule . /index.php [L].

C2 · A3

Header and footer links go to their own pages

HighDone in development (Oct 5)

Decision: every menu item, contact button and footer site map link points to its own page address now, even if that page is not built yet and shows a 404 for the moment. The links start working as each page in the page plan is published, with no further code change. Facebook and X use dummy addresses until the official accounts are confirmed.

The Privacy Policy link already pointed to /privacy-policy/ and is unchanged. rightcore_news_list_url() returns the page that uses the 「News一覧」 template, or /news/ if there is none.

Dummy addresses: replace with 【official Facebook URL】 and 【official X URL】 once the manager confirms the accounts, or delete the icons if the accounts do not exist (A3, A14).

C3 · A3

もっと見る buttons and service card links go to their pages

HighDone in development (Oct 5)

Same decision as C2: no # or empty links. Each button points to the page it describes, even if that page is a 404 for now. The homepage now has no href="#" and no empty href="" links (the hidden "skip to content" link #main-content stays; it is an accessibility jump, not a placeholder).

When the Service page is built, give its four sections the ids creative, design, media and global so these links jump to the right place. If each service gets its own page later (page plan P2), change the links to those addresses.

The FAQ button already links to /faq/ and is unchanged. The Works button links to the Works list (get_post_type_archive_link( 'works' )).

C4 · A11

One heading per service and unique section ids

Low

Each service name is an <h2> twice (card and hover overlay), and id="about-title" appears three times. Each section's aria-labelledby must match its own heading id.

Copy the overlay h2 styles to .title-block__name so the look does not change. Service names are H3 under the section's H2; change the card heading (lines 32, 68, 104, 140) from h2 to h3 if the section title is the H2.

Search the CSS and JS for #about-title before renaming, and update any selector that uses it.

C5 · A6, A7

Image loading, width/height and alt text

High

The first MV photo is the largest item on screen (LCP): load it immediately with high priority. Every other image below it loads lazily. Every <img> gets width and height equal to the file's real pixel size (only 19 of 42 have them now).

If the slider shows mv02 first (the audit measured mv02 as LCP), put fetchpriority="high" on whichever slide is visible on first load, and only that one.

Alt text rules

  • Photos that carry meaning (MV, About, Recruit): short, factual Japanese description.
  • Images that show text: repeat that text.
  • Decorative images (bullets, icons next to a label, avatars next to a name): keep alt="".
  • Service card images currently say alt="Avatar": change to alt="" (the card heading already names the service).

C7 · A6, A21

Compress image files and remove unused ones

Medium

Target: each photo under about 300 KB, about twice its largest displayed width. Keep the originals outside the theme folder.

If you switch a file to .webp, update the file name in the PHP and in any CSS background-image: url(...).

Local check found mv-img.png referenced in an older mv.php. Run the command on the current theme before deleting.

C8 · A1

Works list and detail templates

High

Without these files WordPress falls back to index.php, which shows only 「RIGHTCORE」. Follow the structure of the News templates already built in development (Oct 5) so both look consistent. Use the same class names as the News templates where possible.

Instagram: do not build templates (an Instagram feed plugin replaces the post type). Turn off its sitemap and set it to noindex in Yoast (Content types › Instagram › search results: off) until then.

C9 · A20

404 page

Low

WordPress sends the 404 status itself; do not add a redirect to the homepage.

C10 · A14

Company details in one place

After details are confirmed

The address, phone and email are typed by hand in several places in footer.php (Access card, contact list, CTA buttons). For MEO they must match the Business Profile exactly. Keep them in one function so a correction is made once.

C11 · A10

Production: one HTTPS address

Medium · production, after approval

Only if the redirect check shows that http:// or the non-preferred www version does not redirect with a 301. Many hosts have an HTTPS switch in their control panel; use that first. Place these lines above # BEGIN WordPress.

Also set Settings › General › WordPress Address and Site Address to the same https:// address. Test in a private window; browsers cache 301s.

C12 · A2, A4, A5, A18, A19

Let Yoast SEO own the <head>

High

Yoast SEO prints titles, descriptions, canonical, Open Graph and JSON-LD (its yoast-schema-graph, which includes Organization and BreadcrumbList) through wp_head(). The theme must not print its own copy. Check header.php matches this and remove any hard-coded tags.
